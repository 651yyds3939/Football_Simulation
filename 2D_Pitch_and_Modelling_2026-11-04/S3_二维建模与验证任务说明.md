## 1. 能否全部采用二维

六项任务均可形成二维阶段的交付物，目标可以表述为：**建立并验证可用于比较机器人足球行为与团队策略的二维抽象仿真环境。**

二维需要明确状态、运动约束、观测和规则，不能仅把三维窗口改成俯视角。二维验证支持模型内部一致性和简化条件下的行为评价；NAO6 关节、平衡、足地接触、相机成像和真实硬件仍需后续独立验证。

本文件解释二维阶段如何落地，不表示导师已同意用二维代替课程全部模型和硬件要求。

## 4. E：足球和机器人模型怎样表示

### 4.1 足球

状态为 `ball = (x, y, vx, vy)`，高度固定为地面滚动高度。用滚动减速度降低速度，速度降为零后停止，不允许减速积分使球反向。

可先检查简单关系：在没有其他接触时，恒定减速度模型的停止时间为 `t_stop = v0 / a`，停止距离为 `d_stop = v0² / (2a)`。

当前 `a = 0.35 m/s²` 是模型假设，不是已经测出的真实球场摩擦；需做来源调查、实验标定或参数敏感性分析。踢球模型还需要保留准备时间和踢空条件，不能把决策发出瞬间等同于成功接触球。

### 4.2 机器人

状态为 `robot = (x, y, theta)`，平面运动可表示为：

```text
x_dot     = v_forward * cos(theta) - v_left * sin(theta)
y_dot     = v_forward * sin(theta) + v_left * cos(theta)
theta_dot = angular_velocity
```

模型要考虑方向速度不同、转身耗时、踢球动作耗时和占地。当前前进约 0.08525 m/s 等值来自已有 Webots 隔离测量，并非实验室 NAO6 实测；圆盘半径 0.15 m也是近似假设。

建议交付名称：**NAO6-informed planar motion approximation / 基于 NAO6 运动约束的平面运动近似**。参数必须逐项写明来源，不能因使用 NAO 的名称就认为已经验证动力学。

## 5. D：二维传感器表示怎样建立

二维不需要先生成真实相机图像，可以建立观测层：

```text
仿真真实状态
    ↓ 相对坐标变换
球相对距离、方向
    ↓ 视野 / 距离限制 / 可选遮挡
可见或不可见
    ↓ 噪声 / 采样周期 / 延迟
带时间戳的观测
    ↓
球员行为决策
```

机器人位置 `(xr, yr)`、朝向 `theta`，球位置 `(xb, yb)`：

```text
dx      = xb - xr
dy      = yb - yr
range   = sqrt(dx² + dy²)
bearing = wrap_to_pi(atan2(dy, dx) - theta)
visible = range <= max_range AND abs(bearing) <= fov / 2
```

这是对可见性的第一层近似，不是 NAO 双相机成像模型。视野、量程、误差和延迟参数应从资料／实验取得，暂定值需标为假设。遮挡若暂不实现，也要说明。

需要分别保留真实状态和观测状态。策略若仍能读取隐藏的真值，就不能宣称正在验证受限传感器条件下的行为；位置估计也需说明是已知位姿、里程计还是定位算法。

可先验证：视野内能看到，视野外不可见；转身后相对方向正确；旧观测延迟符合设置；丢球后按明确规则处理。当前这些是建议工作，尚未在本次加入现有控制器。

建议先做以下验证，不依靠一场进球判定模型正确：

| 检查 | 预期依据 |
|---|---|
| 场地与边界 | 尺寸与课程表、模型、裁判一致 |
| 直行与转向 | 无接触时位移约为速度乘时间，角度按角速度更新 |
| 足球自由滚动 | 停止时间／距离与公式相符，步长减小后结果收敛 |
| 整球进门 | 部分越线不算、完整通过净开口才计分 |
| 观测层 | 可见性、噪声和延迟符合各自定义 |
| 可重复性 | 同版本、同种子、同条件可复现 |
| 参数敏感性 | 改变未标定参数时，记录结论是否反转 |
| 二维与三维对照 | 同一行为场景在动作限制下是否仍能执行；不能要求轨迹完全一致 |

部分运动和判球检查在现有程序中已有记录；新传感器项、步长收敛和完整参数验证仍需补充。验证记录应注明来源、条件、结果和未通过项。
