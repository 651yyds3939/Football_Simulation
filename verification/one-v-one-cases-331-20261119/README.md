# 七例 1v1 回放证据

- build_cases.py：用当前策略重新计算七个固定种子，并按每步接触和控球记录分类。
- summary.json：来源哈希、分类及关键事件。
- 数字命名 JSON：每例原始轨迹和事件；records.json 为合并轨迹。
- build_viewer.py：生成根目录离线 HTML。
- run_browser.py、browser.mjs：浏览器交互检查，并按8倍生成视频。
- browser-video-check.json：七例、自动切换、关键帧、双语、离线运行和视频帧数检查。
- chapters.ffmetadata、video-delivery-check.json：MP4章节及编码检查。
- source-unchanged-check.json：一攻一防原文件哈希复核。

这是指定比例的案例选集，不代表总体进球或抢断成功率。
