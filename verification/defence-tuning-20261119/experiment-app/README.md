# 一攻一防 2D 演示：Windows 使用说明

这是一个机器人足球测试场景：红方进攻右侧球门，蓝方拦截、抢球和解围。二维版保留了分离时与 Webots 相同的 Python 决策代码快照，现在独立运行；运行这个包不需要安装 Webots。

## 只看演示，不用安装

先完整解压压缩包，再双击：

- `example_replay.html`：看一次进攻进球。
- `defence_replay.html`：看一次防守成功。

浏览器打开后点击 **Play**。这两个文件是录好的回放。

## 自己运行，换不同开局

1. 安装 [Python 3.8 或更新版本](https://www.python.org/downloads/windows/)，安装时如有 **Add Python to PATH**，勾选它。
2. **完整解压**压缩包，不要在压缩包里直接运行。
3. 双击 `start_windows.bat`。
4. 浏览器打开后，点击 **Play** 开始。

运行时保持弹出的黑色窗口打开。结束时关闭黑色窗口和网页即可。

## 页面怎么用

- **Play / Pause**：开始 / 暂停。
- **New random setup**：换一个随机开局。
- **Repeat seed**：重新运行当前开局。
- **Playback**：播放速度，默认 **8 倍**。
- **中文**：切换中文界面。

## 遇到了什么问题，做了什么调整

- **每次结果一样**：同一个种子会重复相同开局，方便对照。想看不同情况，点击 **New random setup**。
- **两个人挤在球旁不动**：加入短暂换位和重新争球，仍有部分僵持场景。
- **防守反应慢、容易被突破**：调整出生位置，让蓝方更靠近本方球门；加入提前预测球路和拦截。
- **转身太慢**：当前行走和转向分开执行，转向期间对手仍能前进。预判只能缓解，步态仍需改进；这还不能认定是真机硬件的极限。

## 简单的测试流程

1. 点击 **Play**，观察接近足球、带球、拦截和进球过程。
2. 遇到卡住或防守失败，记下页面下方的 **Seed（种子）**，点击 **Download run data** 保存记录。
3. 点击 **Repeat seed** 重测相同开局；比较修改前后时，保持种子、时长和设置相同。
4. 点击 **New random setup** 多试几个开局，或点击 **Fast test ×20** 一次计算 20 次，查看整体结果。

倍速只让测试播放得更快，不会提高机器人的运动能力。不要只看一次进球就判断策略好坏。

## 目前测试到什么程度

相同的 100 个随机开局、每局 180 秒仿真时间，运动参数保持一致：

| 结果 | 改进前 | 改进后 |
| --- | ---: | ---: |
| 红方进球 | 82 | 63 |
| 蓝方断球后推进至左侧球门进球 | 18 | 33 |
| 超时 | 0 | 4 |

防守表现有所改善，但仍有失球，部分贴身僵持也变长了。超时不算防守成功。这些只是简化二维模型的结果，不代表三维或真机的成功率。

后续重点是测准转向速度、验证边走边转的步态，再继续做三维和真机测试。

## 打不开怎么办

- 提示找不到 Python：先安装 Python，再双击启动文件。
- 浏览器没自动打开：复制黑色窗口里的网址，到浏览器地址栏打开。
- 不要直接双击 `viewer.html`，实时运行请双击 `start_windows.bat`。

这是简化的二维测试：行走和转向分开，仍可能出现防守失败或僵持，不模拟摔倒。
