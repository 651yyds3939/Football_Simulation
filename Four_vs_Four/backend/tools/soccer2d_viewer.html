这个场景能验证什么？
  • 展示现有 Python 二维模型实际产生的位置、决策标签、动作选择和比赛事件；播放速度只改变查看速度。
  • 圆盘运动与接触是简化模型；不模拟 NAO 关节、平衡、跌倒、相机定位和球的飞行。
  • 朝向与位置是离散记录，画面不在半场摆放或裁判重置之间补画运动。行为标签不是技能成功的证明。
  • 双方策略以比分旁的标签为准。半场阵型摆放属于测试夹具。
  • 界面用于观察已生成的比赛，不能拖动球员或改变正在播放的比赛结果。修改策略后重新生成场景。
