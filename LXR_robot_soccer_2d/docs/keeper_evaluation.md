# 守门员参数选择与配对评估（GK-14、GK-15）

新版默认采用 **`gap = 0.5 m`、`max_out = 1.5 m`**。相对新版暂用配置，这组参数在扫描中降低了远角扑救场景和练习赛的失球率。

独立验证中，与 MATLAB 基线相比，真实感知下的远角场景失球率从 **16.00% 升到 24.85%**。失球增量主要出现在 MATLAB 提前解围的配对中。MATLAB 在 8 s 准备期内提前解围 **987 次**，其中 **340 次**对应新版失球。射手在球后静止等待是测试设定，实际比赛中射手可以提前射门。

练习赛失球率从 **76.65% 降到 75.30%**，差值的 95% 区间跨过零。新版超时 **60 次**，MATLAB 基线为 **16 次**。失球率把超时计入全部尝试，因此应结合超时次数解读。

## GK-15 独立复跑

在更新门线判定后，使用独立种子 `2503`。均匀瞄准和远角瞄准各在完美、真实感知下测试，每个组合 **2,000 对**。双方均用真实感知的练习赛另跑 **2,000 对**。对照组在同一个 Python 仿真中使用 MATLAB 门将策略，两组共享运动、球物理和裁判模型。

- **全部尝试失球率**用 `goal / 全部配对尝试`。提前解围属于未失球，练习赛的射失和超时也留在分母内。
- **共同有效射门扑救率**只统计两版均判为 `goal` 或 `saved` 的配对。对同一批配对计算两版的扑救率和差值。真实感知远角组的 593 对共同有效射门中，扑救率从 46.04% 升到 73.52%。1.0–1.5 m 档的失球增量超过了较远距离档的失球降幅。
- **距离分组**使用两版共享的起始球位到球门中心的距离。扑救场景使用预设射门点，练习赛使用球的起始位置。每档含下限，末档也含上限。受 2 m/s 射门可达约束，本次远角样本的 2.0–2.3 m 档只有 3 对，该档结果仅作描述。
- **配对与统计**按试验编号核对站位和球位。扑救场景复用完整出球速度和方向。练习赛每次从两版共同的随机种子开始，各自轨迹会改变后续取样。差值统一为「新版 − MATLAB」，单位为百分点。95% 区间由 5,000 次成对重抽样得到，p 值使用双侧精确 McNemar 检验。分档 p 值未做多重比较校正。[成对重抽样与百分位区间](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html) · [精确 McNemar 检验](https://www.statsmodels.org/stable/generated/statsmodels.stats.contingency_tables.mcnemar.html)

## 复跑命令

在本 Python 项目目录运行。命令输出 JSON，包含各结果次数、配对变化和起始条件校验值。`--workers` 控制并行数。

```bash
python3 -m robot_soccer.simulations.evaluate_keeper tune --attempts 500 --seed 2501 --workers 7
python3 -m robot_soccer.simulations.evaluate_keeper final --attempts 2000 --seed 2503 \
  --gap 0.5 --max-out 1.5 --workers 7
```

生成和统计代码见 [evaluate_keeper.py](../robot_soccer/simulations/evaluate_keeper.py)。
